# 上海历史文化名镇公众感知数据

本数据集包括两个数据表，每表提供 UTF-8 CSV 格式。

## rawdata

共5,365条古镇—笔记记录，对应5,048篇独立笔记。同一篇笔记涉及多个古镇时，分别记录与各镇的关系，因此笔记ID可重复，`古镇＋笔记ID`为联合主键。

| 字段 | 含义 |
| --- | --- |
| 古镇 | 笔记所关联的研究古镇 |
| 笔记ID | 平台笔记标识，按文本读取 |
| 标题 | 笔记标题 |
| 正文 | 采集的笔记正文 |
| 话题标签 | 笔记附带标签；保存供查阅，不作为本轮正文语义编码依据 |
| 发布时间 | 源数据记录的发布时间，不是采集时间 |

## results

共15,880条结构化语义记录:以句末标点、分号、换行和列表标记初步切分笔记正文，再结合上下文划定语义单元。对不同对象的独立表述分别编码，对同一对象的连续描述或判断保留其否定、转折和条件关系。按此口径，从3,537篇笔记中提取15,880条结构化语义记录。

涉及3,537篇独立笔记:5,048篇独立笔记中，3,537篇形成15,880条可归入目标古镇的语义记录，其余1,511篇中，283篇无实质正文，401篇未识别出与目标古镇相关的独立表述，827篇仅涉及古镇周边或地点归属不明。

每行保留一个既有编码记录的对象、评价和情感对应关系。`语义单元ID`为唯一主键；以`古镇＋笔记ID`关联rawdata。rawdata中没有对应结果的笔记仍保留在笔记样本库中，不解释为中性或负面评价。

| 字段 | 含义 |
| --- | --- |
| 语义单元ID | 结构化记录的唯一标识 |
| 语义组ID | 关联同一语境或相邻判断的语义组标识 |
| 古镇 | 该语义记录对应的古镇 |
| 笔记ID | 原始笔记标识 |
| 感知维度 | 历史文化与遗产、空间与环境、日常生活与社会交往、商业与游憩活动、交通与公共服务之一 |
| 具体对象 | 记录中的具体感知对象名称 |
| 标准对象名称 | 用于归并统计的对象名称 |
| 语义表述 | 对应对象的语义表述，非必然逐字引文 |
| 评价倾向 | 正面、负面、褒贬并存、不明确 |
| 情感类别 | 同义归并后的现有情感类别，保留原标签 |
| 情感原词 | 数据中保存的情感原词 |
| 情感主体 | 情感表达所指主体，保留原标签 |
| 原文依据 | 支持该记录的文本依据 |


数据表保留完整记录，不用特定图表的频次阈值。频次筛选后的图表记录数可少于本表；比较古镇时说明统计单位、筛选条件和占比分母。语义记录数不等于笔记数或独立人数。数据反映采集范围内的平台表达。

## 分类规则与复现

`复现材料/分类原则与复现说明.txt`说明语义单元边界、五类归属、同义名称、评价及情感判定原则，以及各图的统计单位和筛选条件。配套名称映射、评价主题对应和图6情感关联清单固定当前版本的统计关系。

使用Python 3运行 `python3 复现材料/reproduce.py`，无需第三方依赖。结果写入`复现材料/复现统计/`。脚本已验证图4的12,128条记录和图7的4,331条正面、376条负面记录。

论文现有正文与数据的差异及建议替换文字见`复现材料/论文数据核对报告.txt`。当前材料支持从已编码数据复算统计；不声称已提供从原始笔记自动重建所有语义标签的完整实验流程。
